# WCAG 2.2 Gap Analysis

**Date:** 2026-04-06
**Scope:** 4 new WCAG 2.2 AA success criteria against shilp-sutra component library
**Result:** 2 PASS, 1 MOSTLY PASS, 1 FAIL

---

## 2.4.11 Focus Appearance — MOSTLY PASS

Focus indicators must be at least 2px thick with 3:1 contrast.

**Primary `.focus-ring` utility:** PASS
- 2px inner ring + 4px outer ring (accent-9 on surface-base)
- Contrast ratio ~7.5:1 (exceeds 3:1 requirement)
- Used consistently on Button, Input, Select, Checkbox, Switch, Slider, Dialog close

**`.focus-ring-sm` variant:** FAIL
- 1px ring (below 2px minimum)
- Used on Badge dismiss button

**Fix:** Increase `.focus-ring-sm` to 2px minimum.

---

## 2.4.12 Focus Not Obscured — PASS

- TopBar uses flex layout (not sticky/fixed) — no obscuring
- BottomNavbar is `fixed` but at bottom — doesn't obscure scrolled content
- Dialog/Sheet use Radix focus trapping with proper z-index stacking
- Z-index hierarchy: sticky(1100) < overlay(1200) < modal(1300) < popover(1400) < toast(1500)

---

## 2.5.7 Dragging Movements — PASS

- Slider: Radix provides full keyboard support (arrows, Home/End, PageUp/Down)
- FileUpload: click-to-select alternative via native `<input type="file">`
- No other drag-only components exist in the library

## 2.5.8 Target Size — FAIL

Interactive targets must be at minimum 24x24px.

| Component | Current Size | Minimum Required | Status |
|-----------|-------------|-----------------|--------|
| Button xs | 28px | 24px | PASS |
| Button icon-xs | 28x28px | 24x24px | PASS |
| Input xs | 28px | 24px | PASS |
| Select xs | 28px | 24px | PASS |
| Dialog/Alert close | 24x24px | 24x24px | PASS |
| **Checkbox/Radio** | **20x20px** | 24x24px | **FAIL** |
| **Switch sm** | **18px height** | 24px | **FAIL** |
| **Badge xs** | **16px height** | 24px | **FAIL** |
| **Badge sm** | **20px height** | 24px | **FAIL** |
| **Slider thumb** | **16x16px** | 24x24px | **FAIL** |

### Remediation options:

1. **Checkbox/Radio (20px → 24px):** Increase `h-ico-md w-ico-md` or add a padding zone. Note: WCAG allows exceptions for inline elements — if checkbox is inline with text, 20px may be acceptable with sufficient spacing.

2. **Switch sm (18px → 24px):** Increase sm track height or rename current sm to xs and make new sm = 24px.

3. **Badge xs/sm:** These are non-interactive when used as labels. Only interactive Badges (with `onClick`) need 24px minimum. Could enforce `size="md"` minimum when `onClick` is present.

4. **Slider thumb (16px → 24px):** Increase from `h-ico-sm w-ico-sm` to `h-6 w-6` (24px).

5. **`.focus-ring-sm`:** Increase from 1px to 2px.
