The gradient-fade variants — keep or cut?

Separator ships 4 variants. Two problems with the 3 gradient ones: (1) they're broken in production — the CSS class interpolates a runtime value (linear-gradient(${deg}…)) that Tailwind 4's scanner can't see, so it never ships the style; (2) a faded-edge divider is a decorative flourish (our anti-convergence layer flags decorative dividers). They're used only in demo stories, never in real components. Below is what they'd look like if fixed.

My recommendation: cut the gradient variants gradient ×3 — keep default (solid) only.
  • They're a decorative flourish (a divider should just divide), and currently invisible in prod anyway.
  • Used only in demo stories — zero real usage, so removal is safe. variant prop goes away; <Separator /> stays a clean hairline.
  • Removing the prop is technically breaking → fold into the 0.45.0 batch (or keep the prop but drop the values). Alternatively: keep & fix by making the classes static per orientation (like Card's cornerPositions map) if you want the fades.
