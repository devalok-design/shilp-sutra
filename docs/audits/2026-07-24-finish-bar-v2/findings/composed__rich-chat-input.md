## Top gaps (prioritized)
- [P0] docs-dx — shipped doc prop table is materially wrong (`onSubmit` signature, invented `maxRows`/`attach`, missing `inline` + 7 props) → regenerate from the interface; document `RichChatInputMessage`. Highest-impact, lowest-risk, and a per-component docs-coverage publish concern.
- [P1] api-composability — replace the 5 bespoke `<button>`s with `IconButton`/`Toggle`/`Button` (threads `disabled`, kills un-tokenized `w-5`/`h-4`, unifies focus/pressed) and rebuild the send-options dropdown on `DropdownMenu` + anchor the emoji picker on `Popover` (deletes 3 outside-click effects + manual Floating-UI) → fixes menu-semantics a11y + StatCard-style drift in one pass.
- [P1] api-composability — `variant` collides with the canonical visual-variant taxonomy → rename to `layout` (or `density`) with a deprecated `variant` alias; never a hard break.
- [P1] motion — add `useReducedMotion` gating to the main file's button swaps + banner entrances; convert `reply-banner`/`attachment-strip`/`schedule-send` from `height:auto` to the `grid-rows-[0fr]→[1fr]` CSS transition already used by the toolbar zones.
- [P2] api-composability — `content` is initial-only → either add controlled `value`/`onValueChange` for the message-edit use case, or rename `content`→`defaultContent` and document the uncontrolled-only contract.
- [P2] accessibility — add `aria-busy`/`aria-live` on the composer region during `isStreaming`; reconsider the error-red stop button (it's a neutral cancel).
- [P2] visual/drift — un-annotated arbitrary values (`w-5`, `h-4 w-px`) → map to `ds` size tokens; leave the annotated component-specific ones (`min-w-[200px]`, emoji `h-[435px] w-[352px]`, `max-w-[120px]`).
- [P2] content-resilience — adopt logical properties + mirrored layout for RTL.

## What it does well
- Zero hard slop tells — clean where most AI-giveaway components fail; all icons are Tabler via the `Icon` API, emoji is a real product feature not decorative.
- Feature completeness genuinely exceeds the reference chat composers (voice/waveform/transcribe/schedule/mentions/slash/reply/streaming).
- Deep engineering-craft: SSR-safe editor, crash-avoidance via ref patterns and no-setState-from-editor-events, lazy emoji picker, optimistic uploads.
- Comprehensive story coverage (20+) and a solid axe-backed test suite.
- Correct surface layering and a focus-ring/spacing/duration language shared with the DS.

## Cross-DS adoption ideas
- **assistant-ui** exposes composer parts as composable primitives (`Composer.Root/Input/Send/Cancel`) with a controlled runtime — we could expose a controlled `value`/`onValueChange` path to close our message-edit gap.
- **Vercel AI SDK UI** normalizes an `attachments`/`parts` message shape and a first-class streaming/stop lifecycle — our `RichChatInputMessage` is close; adopting a `status` union (`ready|submitted|streaming`) instead of the boolean `isStreaming` would map cleaner and unblock `aria-busy`.
- **Radix/Base UI `DropdownMenu` + `Popover`** (already vendored in this DS) give focus-trap, roving focus, `menuitem` semantics, and portal positioning for free — importing them here deletes ~3 bespoke outside-click effects and the manual Floating-UI wiring.
- **cmdk / Base UI Combobox** virtualized async listbox — our mention/slash suggestion lists cap at `.slice(0,8)` with no virtualization or async-loading state; worth considering for large directories.

## Rebuild note
**Polish, not rebuild — but a large polish.** The architecture is sound (TipTap engine, zone layout, structured message output, crash-hardened state model) and the feature set is best-in-class; there is no structural reason to start over. The work is a coordinated in-place pass: (1) fix the doc drift, (2) swap the 5 hand-rolled buttons + 2 re-rolled overlays for DS primitives, (3) rename `variant`→`layout` with an alias, (4) unify motion (reduced-motion guard + grid-rows over height:auto), (5) streaming a11y, (6) decide controlled-vs-uncontrolled `content`. Each is independent and low-risk; together they move it from 3 to a solid 4. None of it changes what the component *is*.
