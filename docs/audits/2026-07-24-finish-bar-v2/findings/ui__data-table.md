# ui/data-table — finish-bar audit

Finish: 3/5   Market: LAGS(MUI X DataGrid)   Rebuild: polish

DataTable is a genuinely-engineered TanStack Table wrapper: sorting, per-column + global filter, client & server pagination, controlled + uncontrolled selection, inline cell editing, row expansion (single-expand), column pinning, virtualization, sticky header, row-click, bulk actions, density, CSV export, column-visibility, mobile card view, loading skeleton, and empty state. It is free of loud visual slop (no accent rails, gradient text, glass/blob, emoji, palette leak), uses role radius tokens throughout (`rounded-control`/`-inner`/`-overlay` — no `rounded-ds-*`/`rounded-full`), composes Card/Checkbox/Button/Skeleton/DropdownMenu/Table, and carries a strong test suite (61 blocks across two integration files + a vitest-axe pass) and real perf engineering (virtualizer, memoized context, stable refs to kill re-render storms). It sits at 3/5 — the same score as the 2026-07-01 baseline — because the composability, keyboard-a11y and motion gaps flagged then largely persist, and a **new dead-class regression** (`border-card-strong`) landed on two inputs since.

## Top gaps (prioritized)
- [P1] accessibility — `onRowClick` rows and double-click-only cell editing are mouse-only; sort + toolbar buttons have no `focus-visible` ring → make rows `tabIndex=0` + Enter/Space + role (or steer keyboard users to an in-row action and document it), add keyboard entry (Enter/F2) to editing, and apply the DS `focus-ring` util to sort/toolbar/edit controls.
- [P1] visual-integrity — `border-card-strong` dead class renders the filter input and page-size select borderless → change to `border-card` (or compose DS Input/Select, which fixes this + the focus-ring holes at once).
- [P1] motion — bulk bar is slide-no-fade, exit-less, and unguarded → move it to framer `AnimatePresence` with `y`+`opacity` on `springs.smooth`, symmetric enter/exit, self-guarded reduced-motion; add a reduced-motion guard to the sort-arrow rotations.
- [P2] api-composability / system-cohesion — replace the 4 raw `<input>`/`<select>` (global search, column filter, cell edit, page size) with DS `Input`/`Select`; accept a `renderBulkActions` slot so consumers can pass real `<Button>`s; export the sub-components for advanced composition.
- [P2] content-resilience — RTL: use logical inset props for column pinning and mirror the pagination chevrons under `[dir=rtl]`.
- [P2] docs-dx — fix bulkActions `color` union in the doc (`'default'|'error'` → `'accent'|'error'`).
- [P3] craft — remove the dead no-op `hideBelow` `if` block in data-table-card.tsx.

## What it does well
- Free of loud visual AI tells; role radius tokens and semantic surfaces throughout; correct dark-mode surface reasoning (sticky header, expanded-row recess).
- Genuinely deep feature set for a DS table (server/client modes, virtualization, controlled selection, expansion, bulk actions, mobile cards) — and it's all typed with generics, no `any`.
- Strong, behavior-level test coverage (61 blocks + axe), not just "renders".
- Real perceived-performance engineering: virtualizer, memoized context, stable refs that killed a documented re-render loop (0.29).
- Sort-arrow and expanded-row motion are tasteful and (for the expander) reduced-motion self-guarded.
- Mobile view now composes `<Card variant="outline">` (baseline F5 fixed) instead of re-rolling a surface.

## Cross-DS adoption ideas
- **MUI X DataGrid / AG Grid** ship full keyboard grid navigation (roving tabindex, arrow/Home/End/PageUp-Down, Enter/F2 to edit) — we have none; this is the single biggest interaction gap for a component called "DataTable".
- **MUI X DataGrid** has column resize + drag-reorder and typed per-column editors (number/select/date) — we coerce every edit to a text `<input>` emitting `unknown`; a `meta.editor` slot would close it.
- **TanStack Table** (our own engine) exposes column resizing, grouping, and aggregation row models we don't surface — low cost to wire in behind flags.
- **Carbon DataTable** announces filter/sort/page result counts via an `aria-live` region — we only have `aria-busy`; a polite live region would help SR users.
- **AG Grid / MUI** offer a batch/pending "commit changes" model for inline editing; our edit commits on blur/Enter with no dirty/rollback affordance.

## Rebuild note
**Polish, not rebuild.** The engine (TanStack + context + already-factored sub-components) is sound and well-tested — no structural reason to rebuild. In-place fixes: (1) swap `border-card-strong` → `border-card` (or compose DS Input/Select, which also fixes the focus-ring holes); (2) add keyboard operability + focus-visible to row-click, cell editing, sort and toolbar controls; (3) move the bulk bar onto framer `AnimatePresence` with fade + symmetric exit + reduced-motion; (4) RTL logical props + mirrored chevrons; (5) doc `color` union fix; (6) remove the dead `hideBelow` block. The larger, *optional* structural item — exporting the sub-components + adding slot escape hatches (`renderBulkActions`) so the flat feature-flag API becomes "easy mode" over a composable core — can be a separate deliberate composition pass, not a prerequisite to ship.
