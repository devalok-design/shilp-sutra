# Designer CLAUDE.md Seed Files

These are personal CLAUDE.md files for each designer contributing to shilp-sutra.

## Setup

Each designer saves their file to their machine at:

```
~/.claude/projects/<project-path>/CLAUDE.md
```

The `<project-path>` is derived from the absolute path to the shilp-sutra repo on their machine. Claude Code creates this directory automatically — they just need to place the file.

**To find the exact path:** Run `claude` in the repo directory, then check `~/.claude/projects/` — there will be a directory matching the repo path (with dashes replacing slashes).

## Files

- `goutham.md` — Display & Identity domain (Phase 1)
- `yogin.md` — Forms & Inputs domain (Phase 1)
- `amal.md` — Containers & Feedback domain (Phase 1)

## Updating

When phase rotations happen, update the "Your Assigned Components" section in each file. The rest stays the same.
