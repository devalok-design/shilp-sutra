# 0.38 Deprecation Sweep Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Cut every `@deprecated`-tagged API in `packages/core` (8 surfaces) and bump bundled dev deps (TipTap 3.22.5, Tabler 3.42.0). Ship as `0.38.0`.

**Architecture:** Single feature branch `chore/v0.38-deprecation-sweep`. One commit per removal so `git bisect` localises any regression. Each commit is self-contained: source change + tests + Storybook + docs (`docs/components/**`, `llms.txt`, `llms-full.txt`) updated together so the CVA-vs-doc audit gate passes after every commit, not just at the end. Two changesets at the end (one `major` for breakages, one `patch` for dep bumps).

**Tech Stack:** pnpm workspaces, Vite 8 (Rolldown), Tailwind 4 (CSS-first), CVA, Vitest, Storybook 10, Changesets, GitHub Actions OIDC publish.
