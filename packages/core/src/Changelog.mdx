## 0.34.x &mdash; Toolchain Upgrade

Full build toolchain upgrade: **Tailwind CSS 4**, **TypeScript 6**, **ESLint 10**, **Vite 8** (Rolldown bundler).

### Breaking Changes

- **Tailwind CSS 3 &rarr; 4:** `outline-none` &rarr; `outline-hidden`, `rounded-sm` &rarr; `rounded-xs`, `backdrop-blur-sm` &rarr; `backdrop-blur-xs`, `!prefix` &rarr; `suffix!` important syntax. Consumers: replace `darkMode: 'class'` with `@variant dark (&:is(.dark *))` in CSS. Peer dep accepts `^3.4.0 || ^4.0.0`.
- **tailwind-merge 3.0 &rarr; 3.5:** Required for TW4 class recognition.
- **TypeScript 5.7 &rarr; 6.0:** `types` defaults to `[]` in TS6. Add `"types": ["node"]` to tsconfig if needed.
- **ESLint 9 &rarr; 10:** Config file lookup starts from linted file directory (not CWD). Verify monorepo configs.
- **react-zoom-pan-pinch 3 &rarr; 4:** `onTransformed` renamed to `onTransform`. Peer dep `^3.0.0 || ^4.0.0`.

### Added

- **Vite 8** with Rolldown bundler + `@vitejs/plugin-react` 6 (Oxc). SSR safety patch for Rolldown CJS interop.
- Bumped React 19.2.5, Storybook 10.3.5, Vitest 4.1.4, framer-motion 12.38, esbuild 0.28, Playwright 1.59.1.

## 0.33.0 &mdash; RichChatInput v2, SplitButton, Schedule Send

### Breaking Changes

- **EmojiSuggestion:** Named export removed. Use `createEmojiSuggestion(set?)` factory.
- **Emoji HTML output:** Non-native `emojiSet` renders `<span data-emoji-id>` nodes, not raw Unicode.

### Added

- **RichChatInput v2** &mdash; Complete rewrite with structured output (`html`, `plainText`, `attachments?`, `voiceNote?`). Zone architecture. 4 variants: `compact`, `expanded`, `minimal`, `inline`.
- **Custom EmojiNode** &mdash; TipTap inline atom node with spritesheet rendering. `emojiSet` prop: `native`, `apple`, `google`, `twitter`, `facebook`.
- **SplitButton** &mdash; `[Action | dropdown]` button with Floating UI positioning and proper ARIA.
- **Schedule Send** &mdash; `onSchedule?(msg, date)` on RichChatInput. Smart presets + DateTimePicker.
- **ButtonGroup rebuild** &mdash; Compound component pattern with context-propagated `disabled`, `attached`, `fullWidth`.
- **Composable toolbar** &mdash; Exported `ToolbarButton`, `ToolbarDivider`, `ToolbarGroup`, and per-format buttons.
- **TipTap v2 &rarr; v3** &mdash; `useEditorState`, SSR-safe `immediatelyRender: false`, `ListKit`. Fixes React 19 crash.

## 0.32.0 &mdash; Button Rewrite, Mobile Responsiveness, Badge Rewrite

### Breaking Changes

- **Button:** `variant="default"` removed (use `"solid"`), `variant="destructive"` removed (use `variant="solid" color="error"`), `color="default"` removed (use `"accent"`).
- **Chip:** Removed. Use `Badge` instead.
- **SegmentedControl:** Rewritten. `variant="filled"` &rarr; `"accent"`, `variant="tonal"` &rarr; `"default"`.
- **TopBar** renders as `<header>`, **Sidebar** as `<aside>`.
- **ResponsiveOverlay:** Deprecated. Use Dialog or Sheet directly.

### Added

- **Mobile responsive overlays** &mdash; Dialog auto-fullscreen on mobile, Sheet auto-bottom with swipe-to-dismiss, Popover renders as bottom drawer.
- **Touch utilities** &mdash; `.touch-target` (44px hit area), `.p-safe` inset utilities, `useTouchDevice()`, `useViewportHeight()`.
- **DataTable `mobileView="card"`** &mdash; Stacked cards below 640px.
- **SegmentedControl redesign** &mdash; White pill + shadow or brand pill, snappy spring animation.
- **Checkbox/Radio `size` prop** &mdash; `sm | md | lg`.

## 0.31.0 &mdash; Variant Audit

- **Alert `size` prop** &mdash; `sm | md | lg`.
- **Card `color` + `size` props** &mdash; Semantic border color, context-propagated sizing.
- **Select `variant` + `color` props** &mdash; `default | outline | ghost`, with `aria-invalid` on error.
- **Tabs `color` + `size` props** &mdash; `accent | neutral`, `sm | md | lg`.
- **Badge `truncate` prop** for ellipsis truncation.
- Server-safe detection via `// @server-safe` source annotations (replaces hardcoded allowlist).

## 0.18.0 &mdash; OKLCH + Framer Motion

Three major system-wide migrations:

- **OKLCH Color Tokens** &mdash; All color primitives migrated from hex shade numbers (50&ndash;950) to OKLCH functional steps (1&ndash;12). Dark mode algorithmically derived.
- **Framer Motion** &mdash; All interactive animations migrated from CSS keyframes to physics-based springs. 37 components migrated. New `MotionProvider`, spring/tween presets, and 6 motion primitives.
- **Toast API rewrite** &mdash; Imperative `toast()` function replacing the old component-based API.
- **Spinner v2** &mdash; State machine (spinning/success/error), filled/bare variants, Framer Motion arc animation.
- **Button `onClickAsync`** &mdash; Promise-driven loading with success/error feedback states.
