Approval workflow.
  1. Open Themer Wizard first — run it end-to-end like a consumer.
  2. Click through each axis playground. Toggle presets. Get a feel.
  3. Read docs/plans/2026-05-25-v040-customization-axes.md top to bottom (especially the cross-cutting concerns: preset versioning, transition strategy, RTL, customer research).
  4. Comment on PR #54 per axis. Approve / skip / defer. Bike-shed names + defaults early.
  5. Approved axes ship as implementation PRs following the v0.39 shape-presets template.

Cross-cutting decisions needed before locking v0.40 scope: preset versioning approach (lock / version / major-bump / hybrid), transition strategy (snap / universal helper / per-axis), visual regression scope (every combo / archetypes only), customer research interviews (Karm, BharatTools, Gurukul, Devalok Hiring teams).
