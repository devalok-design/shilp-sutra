How to read these. Each playground is self-contained — no build, no dependencies. Open in any browser. The sidebar exposes preset switches; the right pane shows mock shilp-sutra components reacting to the role tokens. The token-snapshot section shows the active values; Copy CSS exports the active preset block ready to drop into your global stylesheet.

Status badges. v0.40 = approved as the next major release; v0.41 = follow-up; v0.42 = power-user feature (component-level overrides, JS theme API).

Plan. Full design + audit gate + codemod approach is in docs/plans/2026-05-25-v040-customization-axes.md. After you click through these playgrounds, approve/skip/defer per axis and we ship implementations one PR at a time, same shape as v0.39.
